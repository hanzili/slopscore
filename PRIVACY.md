# Privacy Policy for SlopScore

**Last updated: January 2025**

## Overview

SlopScore is a Chrome extension that displays contributor reputation badges on GitHub pull request pages. We are committed to protecting your privacy.

## Data Collection

**We do not collect any personal data.**

SlopScore operates entirely within your browser. No data is sent to our servers because we don't have any servers.

## Data Storage

The following data is stored locally in your browser only:

- **GitHub Personal Access Token**: Stored in Chrome's local storage to authenticate API requests. Never transmitted anywhere except directly to GitHub's API.
- **Cached contributor data**: Temporarily cached locally to reduce API calls and improve performance.

## Third-Party Services

SlopScore makes API calls directly from your browser to:

- **GitHub API** (api.github.com): To fetch public contributor data and pull request information.

These requests go directly from your browser to GitHub. We do not proxy, intercept, or store any of this data.

## Permissions

- **Storage**: To save your GitHub token and cache contributor data locally.
- **Host permissions for github.com**: To display badges on GitHub PR pages and make API calls.

## Data Sharing

We do not share any data with third parties because we do not collect any data.
